# Сюда кидать модели из Meshy

Кладёшь GLB как скачал из Meshy (ничего не уменьшая), коммитишь в main и пишешь мне: «новые модели в main».
Дальше я подключаю их в игру сам: размер, поворот, столкновения, место в комнатах, оптимизация.

## Папки

- `furniture/` — мебель и крупные вещи, на которые крыса залезает (стол, шкаф, кровать, стиралка)
- `props/` — мелкие вещи в комнатах: для красоты или чтобы ронять (кружка, банка, книга, чайник)
- `food/` — еда, которую крыса носит в гнездо
- `finds/` — находки-секреты для гнезда
- `characters/` — персонажи и животные (хозяин, кот, собака); лучше уже с анимациями
- `rooms/` — части комнат и норы (гнездо, окно, люстра)

## Имена

Как в списке в документе: `kettle.glb`, `cat_bowl.glb`. Новая вещь — любое имя латиницей без пробелов,
и напиши мне, где она должна стоять.

## Что я делаю с моделью

Пропорции не трогаю. Уменьшаю число треугольников и текстуру только чтобы игра не тормозила (сырые файлы
Meshy весят 10–80 МБ): мебель до ~20 000 треугольников и текстура 2048 (раньше было 5–8 тысяч и 1024, поэтому
модели и выглядели хуже). Оригинал остаётся здесь, его всегда можно переделать заново.

Файл больше 100 МБ GitHub не примет — такой пришли в чат.
