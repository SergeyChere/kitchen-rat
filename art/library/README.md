# Free model library

Ready-made models (about 28 MB) to use as they are or as a starting point in Blender. Everything here is public domain
(CC0 1.0): free for a commercial game, no credit required. The game itself still uses the models generated by
`tools/blender/` (`godot/assets/models/`); pieces from here can replace them one by one.

## Quaternius (`quaternius/`)

297 low-poly models by [Quaternius](https://quaternius.com), taken from the OpenUSD copy at
[chibifire-stages/quaternius-stage](https://github.com/chibifire-stages/quaternius-stage) and converted to `.glb` by
`tools/blender/convert_library.py`. Open them in Blender with File → Import → glTF, or drop them into Godot.

| Pack | Models | What's useful for Kitchen Rat | Preview |
|---|---|---|---|
| Ultimate Home Interior | 123 | kitchen cabinets, fridge, oven, sink, couches, chairs, lamps, curtains, carpets, plants, doors, drawers, washing machine, beds | [preview](quaternius/preview_UltimateHomeInterior.png) |
| Ultimate Food | 103 | cheese, bread, sausage, chicken leg, pizza, cookies, plates, pots, pans, cutlery, bottles, jars | [preview](quaternius/preview_UltimateFood.png) |
| Furniture | 23 | beds, bookcases, chairs, coffee tables, lamps, sofas, stool, table, vases | [preview](quaternius/preview_Furniture.png) |
| Ultimate Furniture | 20 | beds, bookcases, desk, doors, nightstand, sofas, stool, tables | [preview](quaternius/preview_UltimateFurniture.png) |
| Junk Food | 16 | cake, cookie, cupcakes, donuts, pizza, burger | [preview](quaternius/preview_JunkFood.png) |
| Ultimate Animated Animals | 12 | Shiba Inu and Husky (the dog), fox; the skeleton is there, the animations are not in this copy | [preview](quaternius/preview_UltimateAnimatedAnimals.png) |

`quaternius/index.json` lists every file with its size in Blender units (the packs are not to real scale: scale a
model to the sizes in the plan's model tables before using it).

## Animated characters (`characters/`)

Rigged and animated, made by `tools/blender/convert_characters.py` from the downloads of `tools/fetch_models.sh`.
The game's rat, pups, cat, dog, owner, kid and guest are built from these by `tools/blender/import_characters.py`
(sized, recoloured, with the game's animation clips made from theirs).
[Preview](characters/preview.png). All CC0.

| File | What | Animations |
|---|---|---|
| `Rat.glb` | Quaternius, Easy Enemy pack: a realistic-ish low-poly rat (Mom / pups) | Idle, Walk, Run, Jump, Attack, Death |
| `Cat.glb` | Quaternius, Animal Pack Vol.2: black cat | Idle, Walking |
| `Dog.glb` | Quaternius, Animal Pack Vol.2 | Idle, Walking |
| `ShibaInu.glb`, `Husky.glb`, `Fox.glb` | Quaternius, Ultimate Animated Animals (the dog of night 17) | Idle ×2, Walk, Gallop, Jump, Eating, Attack, Hit, Death |
| `Cat_Cube.glb`, `Dog_Cube.glb` | Kenney, Cube Pets: cute blocky style | idle, walk, run, eat, dance, gestures |
| `Man_Casual.glb`, `Man_LongSleeve.glb`, `Woman_Casual.glb`, `Woman_Dress.glb` | Quaternius, Animated Men / Women: the owner | Idle, Walk, Run, Jump, Sitting, Standing up, Death, Punch, Clapping… |

## Kenney (`kenney/`)

[Furniture Kit](kenney/preview_furniture.png) (140: kitchen cabinets, fridges, stove, microwave, toaster, blender, coffee
machine, sofas, beds, lamps, TVs, washer, rugs, plants, trash can, cardboard boxes) and
[Food Kit](kenney/preview_food.png) (200: cheese, bread, fruit, vegetables, sausages, pizza, cakes, plates, pans,
bottles). Kenney, CC0. The `.glb` files share `Textures/colormap.png` next to them: keep the folder together.
