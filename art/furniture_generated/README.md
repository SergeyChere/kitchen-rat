# Replaced generated furniture

The game's own models (made by `tools/blender/furniture.py`) for the pieces that now use Quaternius library models
(CC0, `art/library/quaternius/UltimateHomeInterior`), swapped in by `tools/blender/library_swap.py`: chair, stool,
side_table, washer, fridge. Copy one back into `godot/assets/models/furniture/` to undo a swap.
