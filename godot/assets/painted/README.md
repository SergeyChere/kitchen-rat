# Картинки для перерисовки

Всё, что игра кладёт на поверхности, лежит здесь. Игра берёт файл из этой папки
раньше любого другого источника, поэтому чтобы заменить картинку своей —
перерисуй её и сохрани **под тем же именем** (PNG). Больше ничего менять не надо.

Сейчас здесь лежат версии, нарисованные скриптом `tools/paint_textures.py`
(акварельные заливки, затёки по краям, неровные линии). Это черновик стиля:
любую из них можно заменить ручной работой.

## Правила

- Размер 1024 × 1024 (можно 2048 × 2048), PNG, без прозрачности.
- Картинка должна **стыковаться сама с собой**: левый край продолжает правый,
  верхний — нижний. Она повторяется по стене или полу много раз.
- Свет и тени не рисуй — их кладёт игра. Нужен только сам материал.

## Узоры поверхностей — серые, цвет даёт сама вещь

Эти картинки игра переводит в серое и умножает на цвет предмета: синий остров
остаётся синим, красная скатерть — красной. Важны только светлое и тёмное:
пятна, мазки, линии. Рисовать можно в любом цвете, но проще сразу серым.

| Файл | На чём лежит |
|---|---|
| `wash.png` | **на всём, что покрашено одним цветом**: шкафы, холодильник, двери, посуда, игрушки. Самая важная картинка: это и есть «акварель» на всех вещах |
| `wood.png` | столешницы, стол, полки, ветки в гнезде (волокна идут слева направо) |
| `wood_dark.png` | тёмное дерево |
| `ceramic_tile.png` | пол на кухне и плитка-фартук над столешницами: 2 × 2 плитки со швами |
| `fabric.png` | скатерть, диваны, шторы |
| `leather.png`, `plastic.png`, `metal_matte.png`, `cardboard.png`, `counter_stone.png` | кожа, пластик, металл, картон, камень |

## Бумага

`paper.png` (512 × 512, серая) — фактура листа. Она ложится поверх всего кадра,
точка в точку с экраном: зерно бумаги видно в каждой заливке, сильнее в тёмных.

## Чего здесь нет

Модели (мебель, крыса, кошка) — это не картинки, а трёхмерные формы с цветами;
перерисовать их нельзя, их цвет и контур задаёт код. Иконка игры — `godot/icon.png`.
